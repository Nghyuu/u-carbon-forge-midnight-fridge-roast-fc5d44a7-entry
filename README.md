A one-line roast of a smart fridge that refuses to open after midnight, written for the [Midnight Fridge Roast](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7) bounty on make.fun.

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` with exactly one trailing newline.
